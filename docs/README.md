## Qué cubre cada archivo

- `README.md`: visión general del workspace.
- `assets/app-map/README.md`: cómo correr y editar el mapa local.
- `assets/app-map/ARCHITECTURE.md`: separación front, datos, backend y persistencia.
- `assets/app-map/ESTADO-MAPA-ACTUAL.md`: estado funcional y pendientes de despliegue.
- `assets/app-map/ESTADO-VISUAL-Y-MODELO-DB.md`: modelo visual y ruta hacia MariaDB.

## Convención básica

- Mantener los cambios del mapa dentro de `assets/app-map/`.
- Usar Markdown para notas de estado, decisiones y handoff.
- No duplicar documentación larga: enlazar la fuente viva.
