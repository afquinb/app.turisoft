## Landing pública

La landing oficial quedó organizada como proyecto independiente en:

[landing](./landing)

Raíz desplegable:

```text
landing/public/
```

Paquete listo para subir al dominio:

```text
landing/dist/turisoft-landing-public.zip
```

## Dominio

Dominio canónico:

```text
https://turisoft.org/
```

La landing estática debe publicarse en el `public_html` del dominio.

## WordPress

WordPress queda separado para trabajo editorial, blog y futuras páginas dinámicas. No debe bloquear la publicación de la landing institucional.
